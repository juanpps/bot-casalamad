# 🤖 Casa Lamad — Bot de WhatsApp & Panel de Atención

Sistema de automatización de WhatsApp y aplicación de escritorio desarrollado por **Juan Miguel Guerrero ([MagnusCode](https://github.com/juanpps))** para **Casa Lamad**.

## 🎯 Qué hace
- **Atención automatizada 24/7:** responde consultas frecuentes, comparte el [menú digital interactivo](https://casalamad.vercel.app) y guía la toma de pedidos.
- **Conexión en tiempo real:** integrado con **Supabase** y WebSockets para sincronizar el estado de la operación.
- **Panel de escritorio:** empaquetado con **Electron** con vinculación rápida por código QR e inicio automático.

## 🛠️ Stack Tecnológico
- **Runtime & Desktop:** Node.js + Electron (electron-store, electron-updater)
- **Mensajería:** whatsapp-web.js + qrcode
- **Datos:** Supabase (@supabase/supabase-js)
